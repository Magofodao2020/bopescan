# ADR 0117 — Portuguese first, graphite theme

- Status: accepted
- Date: 2026-10-15
- Scope: B.O.P.E Scanner (modified version of aeterna-rongroi 0.9.0)

## Decision

pt-BR is the default UI and CLI language; English and Thai stay. The theme is dark graphite with state
colours (OK green-grey, INFO blue, WARN amber, FLAG red, NOT CHECKED striped grey) that never rely on
colour alone — every state also has its word.
